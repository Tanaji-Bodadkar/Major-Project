# Carbon Intelligence Platform — Carbon Methodology

## Overview

The carbon estimation pipeline converts estimated electrical energy consumption into
an estimate of operational carbon dioxide equivalent (CO₂e) emissions.

```
Estimated Power (W)
        ↓ × time
Estimated Energy (Wh / kWh)
        ↓ × carbon intensity
Estimated CO₂e (g / kg)
```

All results are **estimates**. The system does not measure actual carbon emissions.

---

## Energy Calculation

### Formula

For a series of power measurements at regular intervals:

```
Energy(Wh) = Σ [ Power_i(W) × Δt_i(s) / 3600 ]
```

where:
- `Power_i` = predicted power at sample i (Watts)
- `Δt_i` = elapsed time since previous sample (seconds)
- Division by 3600 converts watt-seconds to watt-hours

### Conversion to kWh

```
Energy(kWh) = Energy(Wh) / 1000
```

### Precision

- Power values are floats (64-bit).
- Energy accumulation uses Python `float` (IEEE 754 double precision).
- Reported to 4 decimal places for kWh, 2 decimal places for Wh.

---

## Carbon Intensity

### Definition

Carbon intensity (CI) represents the mass of CO₂ equivalent emitted per unit of
electrical energy generated by the grid at a given time and location.

**Standard unit:** gCO₂e/kWh

### Primary Source: Electricity Maps

- **API:** Electricity Maps Carbon Intensity API v3
- **Endpoint:** `GET https://api.electricitymap.org/v3/carbon-intensity/latest?zone={zone}`
- **Returns:** real-time carbon intensity for a grid zone in gCO₂e/kWh
- **Coverage:** ~200 grid zones worldwide
- **Update frequency:** ~15 minutes

Documentation: https://docs.electricitymap.org/

### Secondary Source: Climatiq

- **API:** Climatiq Electricity Emission Factors
- **Endpoint:** `POST https://beta.api.climatiq.io/estimate`
- **Use case:** fallback if Electricity Maps is unavailable or zone not found
- **Returns:** kgCO₂e per kWh for a specified country/region

Documentation: https://www.climatiq.io/docs

### Fallback Mechanism

If both APIs are unavailable, a static regional factor may be used **only if**:
1. It is configured in `config.py` with a documented source.
2. The UI clearly labels it as: `Using fallback factor — live data unavailable`.
3. The source and publication year are shown.

Example fallback values (must be replaced with up-to-date official figures):

| Region | Factor (gCO₂e/kWh) | Source |
|--------|---------------------|--------|
| India (national avg) | 708 | CEA 2022 Annual Report |
| UK | 233 | UK DESNZ 2023 |
| EU average | 276 | EEA 2022 |
| USA average | 386 | EPA eGRID 2022 |
| Global average | 436 | IEA 2022 |

**These static values are not used as defaults in production.** They require explicit
configuration and are clearly labeled when active.

## CO₂e Calculation

### Formula

```
CO₂e(gCO₂e) = Energy(kWh) × CarbonIntensity(gCO₂e/kWh)
```

Or equivalently:

```
CO₂e(kgCO₂e) = Energy(kWh) × CarbonIntensity(kgCO₂e/kWh)
```

### Unit Convention

The system internally stores CO₂e in **grams (g)** for precision at typical computing
scales (where kWh values are small).

The UI displays:
- Values < 1000 g → displayed as `g CO₂e`
- Values ≥ 1000 g → also shown as `kg CO₂e` for readability

## Scope of Emissions

This system calculates **Scope 2 operational emissions** only:

> **Scope 2:** Indirect emissions from purchased electricity consumed by the system.

It does **NOT** calculate:
- Scope 1 (direct combustion — not applicable to computing)
- Scope 3 (embodied/manufacturing carbon of hardware)

This is documented in the dashboard and reports.

---

## Limitations

1. Carbon intensity varies in real time; the API provides a ~15-minute granularity.
2. Grid zone assignment is based on user-configured region; if misconfigured, intensity
   will be for the wrong grid.
3. This methodology covers operational electricity use only, not hardware manufacture.
4. Transmission and distribution losses are not separately modelled (they are partially
   included in the grid mix carbon intensity factor from Electricity Maps).

---

## Display Requirements

The UI must display at all times:

- Carbon intensity value with unit (gCO₂e/kWh)
- Data source (Electricity Maps / Climatiq / Fallback)
- Zone / region
- Timestamp of last intensity update

Example:
```
Carbon Intensity: 520 gCO₂e/kWh
Source: Electricity Maps (zone: IN-WE)
Updated: 14:30
```

Or when unavailable:
```
⚠ Carbon intensity unavailable — fallback factor in use (708 gCO₂e/kWh, CEA 2022)
```
